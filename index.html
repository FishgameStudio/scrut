Scrut

A lightweight, simple & helpful CLI tool for code scrutiny, developed in Rust.

Why scrut?

Performance

Scrut is developed in Rust, bringing memory safety, excellent runtime performance and lightweight binaries.

Usability

Scrut features human-written documentation and an approachable introductory guide. Commands are simple to use, and scan results are presented in easy-to-understand formats.

Productivity

Scrut turns routine security and quality checks into one fast command. Scan specified files, generate checksums and secrets, and get actionable diagnostics directly in your terminal.

Quick start

Show the version of the program:

scrut version

Scan the current project with one command:

scrut scan all

Or focus on a specific type of issue:

scrut scan secrets quality

What Scrut checks

  • Secrets, including passwords, personal access tokens and JSON web tokens.
  • Unsafe patterns, including destructive commands and unsafe pointer operations.
  • Hard-coded values, including paths, URLs, email addresses and time zones.
  • Quality issues, including debug macros, TODO markers and unreachable code.

Useful workflow

# Check a project
scrut scan all

# Generate a strong password
scrut generate password --len 24

# Create SHA256 checksums for release files
scrut generate checksum

# Inspect diagnostic logs
scrut log

Actionable diagnostics

Scrut reports the rule, file, line number and matching source code, so issues can be understood directly in the terminal. 

Password: file src/config.rs, line 12:
12 | let password = "development-password";
