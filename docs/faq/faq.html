Frequently Asked Questions

Having problems with scrut? Here's the frequently asked questions, hope they're helpful to you.
Why does Scrut report false positives
Scrut uses static pattern matching. Some code patterns may trigger false‑positive alerts. Adjust your path exclude rules to skip known‑safe code files.
How can I ignore certain files
Use the −e,--exclude <path> flag to exclude files or directories from scanning.
Where is Scrut's log file stored
Scrut stores global log files at ~/scrut.log.
