Getting Started

Here's the documentation of command scrut.

Synopsis

        scrut [-v|--verbose] [-c|--confirm] [--max-log-size <MiB>] [--config-file <File>] [-C|--curr-dir <Directory>] <command> [args]

Options

  • −v,--verbose: Enable verbose logging. It will print many things if you enabled it.
  • −c,--confirm: Confirm before actions. ("Actions" include writing files, renaming directories, etc.)
  • −−max-log-size
    • : Set the maximum size of the log file (~/scrut.log). The unit of the size is MiB
  • --config-file: Specify a new path of the configuration file. The default config file is ~/.scrut/config.toml (if the configuration is initialized).Panics if the format is invalid. See command config for more information.
  • −C,--curr-dir: Run as if scrut was started in the specified path instead of the current working directory. If the path is present but empty, e.g. -C "", then the current working directory is left unchanged.

    • Commands

  • version: Show current version of scrut
  • docs: Open web page of Scrut Docs with default browser
  • scan: Scan issues in specified files
  • fix: Fix known issues in specified files
  • log: Print contents of the log file
  • generate: Generate specified items
  • gen: Alias for command generate

    • Panics

    Scrut panics if no command provided or specified in command-line.
