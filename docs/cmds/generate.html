Name

scrut generate · Generate specified items.

Synopsis

        scrut [generate|gen] <ITEM> [-l|--len <length>] [-r|--range <start> <end>] [-c|--content <string>] [--from-file <filename>]

Description

Generate one specified item and print it. The item is required and single, it includes:
  • password: A strong password
  • randint: A random integer
  • randfloat: A random floating-point number
  • sha256: SHA256 hash of a specified content or file
  • checksum: A Standard checksum file named SHA256SUMS

Options

  • −l,--len: The length of something. It is necessary if the item needs a valid length.
  • −r,--range: The range of something. It's necessary if the item needs a specified range.
  • −c,--content: The content to generate SHA256 hash. It's necessary if the item needs complete content.
  • --from-file: The name of the file. The program will read content of the specified file and pass the content to the --content param. The option --from-file has higher priority than the option --content. It's necessary if the option --content is necessary.

Panics

Panics if the necessary arguments wasn't given.
