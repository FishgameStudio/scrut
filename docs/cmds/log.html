Name

scrut log · Print contents of the log file.

Synopsis

        scrut log

Description

Print full contents of the log file without any pager. You can execute this command to page printing: 
        scrut log | more

Options

This command has no extra command-line options.

Panics

Panics if unable to access the log file (~/scrut.log).
Note: In the vast majority of cases, it will not panic because the log system is already initialized before executing this command.
