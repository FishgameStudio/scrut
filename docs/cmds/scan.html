Name

scrut scan · Scan specified types of issues in current working directory.

Synopsis

        scrut scan [ITEMS]... [-e|--exclude <path>...] [-a|--scan-all]

Description

Scan and find issues in commited files if possible. Types of issues includes:
  • secrets: Commited personal secrets in git. Including hard-coded passwords, PATs, etc.
  • evils: Malicious contents. Including evil scripts, processes, commits, etc.
  • hardcoded: Hard-coded contents. Including path, URI, email, etc.
  • quality: Code quality test. Including empty loops, todo! macros, etc.
  • all (aka "*"): All issues. All of the above types are included.

Options

  • −e,--exclude: Exclude paths matching the given path; skip these filesduring scanning. ".git/*" and "target/*" will be excluded.
  • −a,--scan-all: Scan all files. ".git/*" and "target/*" are excluded.

    • Panics

    Panics if the type of item is not recongnized.
