Name

scrut config · Manage configuration of scrut.

Synopsis

        scrut config <subcommand> [args]
        scrut config print
        scrut config show
        scrut config set <Key> <Value>
        scrut config init [-f|--forcibly]

Description

Manage configuration files of scrut. The configuration is centrally stored at the directory ~/.scrut.

Sub commands

  • Print

    Print the raw content of the main config file (~/.scrut/config.toml). 
                    scrut config print
    No extra options.

  • Show

    Show the prettily formatted structure of the config file. 
                    scrut config show
    No extra options.

  • Set

    Modify the config file with the given key and value. 
                    scrut config set <Key> <Value>
    • Key: The name of the config you want to change.
    • Value: The value you want to assign to the key.
    Panics if the key is unknown.

  • Init

    Initialize the configuration system. 
                    scrut config init [-f|--forcibly]
  • −f,--forciblyForcibly reinitialize the config.

Options

This command doesn't own a command-line options.

Panics

Panics if the sub command isn't provided.
